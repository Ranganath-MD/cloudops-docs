---
title: Alerting
description: Actionable alerts tied to SLOs
---

Alerts should page on user impact, not every noisy metric spike.

<Callout title="Alert hygiene" type="idea">
  Every alert needs an owner, a runbook link, and a clear next action.
</Callout>

```yaml tab="Prometheus"
groups:
  - name: api-slo
    rules:
      - alert: HighErrorRate
        expr: |
          sum(rate(http_requests_total{code=~"5.."}[5m]))
          /
          sum(rate(http_requests_total[5m])) > 0.01
        for: 10m
        labels:
          severity: page
        annotations:
          runbook: https://docs.example.com/runbooks/high-error-rate
```

```text tab="Checklist"
- Severity defined (ticket vs page)
- Deduplication / grouping configured
- Silence windows for maintenance
```
