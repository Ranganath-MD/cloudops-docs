Observability answers what broke, where, and why — without SSH into every host.

## Three signals

1. **Metrics** — trends and alerts
2. **Logs** — event detail
3. **Traces** — request path across services

<Callout title="SLOs first" type="warn">
  Define service level objectives before adding dashboards. Alerts should map to user impact.
</Callout>

## Example PromQL

```text tab="Availability"
sum(rate(http_requests_total{code!~"5.."}[5m]))
/
sum(rate(http_requests_total[5m]))
```

```text tab="Latency"
histogram_quantile(
  0.99,
  sum(rate(http_request_duration_seconds_bucket[5m])) by (le)
)
```
