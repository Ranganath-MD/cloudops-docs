Prometheus scrapes metrics. Grafana turns them into dashboards and alerts.

## Setup goals

1. Install Prometheus and Grafana
2. Scrape an application or node exporter
3. Build a pipeline / cluster dashboard
4. Create a basic alert rule

```yaml tab="prometheus.yml"
global:
  scrape_interval: 15s
scrape_configs:
  - job_name: 'api'
    static_configs:
      - targets: ['api:8080']
  - job_name: 'node'
    static_configs:
      - targets: ['node-exporter:9100']
```

```text tab="Queries"
# Request rate
sum(rate(http_requests_total[5m]))

# Error ratio
sum(rate(http_requests_total{code=~"5.."}[5m]))
/
sum(rate(http_requests_total[5m]))
```
