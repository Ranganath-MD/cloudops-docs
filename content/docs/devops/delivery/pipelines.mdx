---
title: Pipelines
description: CI/CD stages for safe delivery
---

Pipelines build, test, and promote artifacts through environments with clear gates.

<Tabs items={['Build', 'Test', 'Deploy']}>
  <Tab value="Build">
    Compile, lint, and produce versioned artifacts or container images.
  </Tab>
  <Tab value="Test">
    Unit, integration, and policy checks must pass before promotion.
  </Tab>
  <Tab value="Deploy">
    Roll out to staging, then production with approval or progressive delivery.
  </Tab>
</Tabs>

```yaml tab="GitHub Actions"
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci && npm test && npm run build
```

```yaml tab="GitLab CI"
stages: [build, test, deploy]
build:
  stage: build
  script: [npm ci, npm run build]
```
