title: Terraform
description: Provision cloud infrastructure as code
---

Terraform declares cloud resources in files so environments are reproducible.

## Terraform vs Ansible

<Tabs items={['Terraform', 'Ansible']}>
  <Tab value="Terraform">
    Best for **provisioning** (create VPC, EC2, AKS). Declarative desired state.
  </Tab>
  <Tab value="Ansible">
    Best for **configuration** (packages, users, app config) after machines exist.
  </Tab>
</Tabs>

## EC2 example

```terraform tab="main.tf"
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "web" {
  ami           = var.ami_id
  instance_type = "t3.micro"
  tags = {
    Name = "lab-web"
    Env  = "training"
  }
}
```

```bash tab="Workflow"
terraform init
terraform plan
terraform apply
terraform destroy
```

<Callout title="Best practice" type="warn">
  Store state remotely (S3 + DynamoDB lock, or Terraform Cloud) for team use — never commit secrets.
</Callout>
