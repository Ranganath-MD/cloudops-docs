Containers package an app with its dependencies so it runs the same on laptop, CI, and cloud.

## Containers vs VMs

| | Container | VM |
| --- | --- | --- |
| Size | Megabytes | Gigabytes |
| Start time | Seconds | Minutes |
| Isolation | Process + namespaces | Full guest OS |

## Core workflow

```bash tab="Pull & run"
docker pull nginx:alpine
docker run -d --name web -p 8080:80 nginx:alpine
docker ps
curl http://localhost:8080
```

```dockerfile tab="Dockerfile"
FROM ubuntu:22.04
RUN apt-get update \
 && apt-get install -y apache2 \
 && rm -rf /var/lib/apt/lists/*
EXPOSE 80
CMD ["apachectl", "-D", "FOREGROUND"]
```

```bash tab="Build"
docker build -t lab-apache:1.0 .
docker run -d -p 8080:80 lab-apache:1.0
```

## Useful commands

```bash tab="Inspect"
docker images
docker logs web
docker exec -it web bash
docker stop web && docker rm web
```
