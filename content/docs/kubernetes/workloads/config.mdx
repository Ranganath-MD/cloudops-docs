description: ConfigMaps, Secrets, and env injection
---

Keep configuration outside the image so the same build can run in every environment.

<Tabs items={['ConfigMap', 'Secret']}>
  <Tab value="ConfigMap">
    Non-sensitive settings such as feature flags and public endpoints.
  </Tab>
  <Tab value="Secret">
    Credentials and tokens — encrypt at rest and restrict RBAC.
  </Tab>
</Tabs>

```yaml tab="ConfigMap"
apiVersion: v1
kind: ConfigMap
metadata:
  name: api-config
data:
  LOG_LEVEL: info
  FEATURE_X: "true"
```

```yaml tab="Secret"
apiVersion: v1
kind: Secret
metadata:
  name: api-secrets
type: Opaque
stringData:
  DATABASE_URL: postgres://app:***@db:5432/app
```
