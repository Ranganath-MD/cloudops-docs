---
title: Upgrades
description: Node and control plane upgrade strategy
---

Upgrade control plane first, then node pools in waves with surge capacity.

<Callout title="Drain safely" type="info">
  Cordon and drain nodes so Pods reschedule before you replace the node.
</Callout>

```bash tab="kubectl"
kubectl cordon node-1
kubectl drain node-1 --ignore-daemonsets --delete-emptydir-data
```

```bash tab="Checklist"
# 1. Backup etcd / confirm managed snapshot
# 2. Upgrade control plane
# 3. Upgrade node groups one AZ at a time
# 4. Verify workloads and ingress
```
