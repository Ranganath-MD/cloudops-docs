## Kubernetes

- RBAC least privilege + short-lived credentials
- NetworkPolicies to limit east-west traffic
- Secrets encryption / external secret stores
- Pod Security standards (no privileged by default)

```yaml tab="NetworkPolicy"
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: api-allow-frontend
spec:
  podSelector:
    matchLabels: { app: api }
  ingress:
    - from:
        - podSelector:
            matchLabels: { app: frontend }
      ports:
        - protocol: TCP
          port: 8080
```

## IaC / CI

- Terraform: remote state, policy checks, no secrets in code
- Jenkins: authenticated users, credential bindings, hardened agents
- IAM: short-lived roles, MFA, audit with CloudTrail / Activity Logs
