## Linux checklist

- Least-privilege file modes (`chmod`, ACLs)
- Understand `passwd`, `shadow`, `group`
- Disable password SSH after keys work
- Keep packages patched

```bash tab="SSH"
# /etc/ssh/sshd_config (lab only after key auth works)
PasswordAuthentication no
PermitRootLogin no
AllowUsers trainee
```

## Docker checklist

- Use minimal base images
- Do not run as root in the container when avoidable
- Pin image tags/digests
- Scan images in CI
- Limit published ports

```dockerfile tab="Safer Dockerfile"
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine
USER node
WORKDIR /app
COPY --from=build /app/dist ./dist
CMD ["node", "dist/server.js"]
```
