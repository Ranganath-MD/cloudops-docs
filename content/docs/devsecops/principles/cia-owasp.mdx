## CIA triad

| Pillar | Meaning | Example control |
| --- | --- | --- |
| Confidentiality | Only authorized access | Encryption, IAM |
| Integrity | Data is not tampered | Checksums, signed commits |
| Availability | Systems stay up | HA, backups, DDoS protection |

## Standards map

- **OWASP Top 10 (2021)** — common web risks
- **OWASP ASVS** — application verification levels
- **OWASP ZAP** — dynamic scanning
- **CIS Controls / Benchmarks** — hardening baselines
- **CVSS / CVE / EPSS / CISA** — scoring and known exploits
