---
title: SAST & DAST
description: Static and dynamic application security testing
---

| Method | Runs against | Finds |
| --- | --- | --- |
| **SAST** | Source code | Injection flaws, secrets, bad crypto |
| **DAST** | Running app | Auth issues, misconfig, runtime bugs |
| **SCA** | Dependencies | Vulnerable libraries |

## Pipeline placement

1. Commit → SCA + SAST (fail on high severity)
2. Build & unit tests
3. Deploy to staging
4. DAST / ZAP baseline scan
5. Promote only if gates pass

```yaml tab="CI sketch"
jobs:
  security:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: SCA
        run: echo "scan lockfiles"
      - name: SAST
        run: echo "run semgrep/sonarqube"
```

<Callout title="Mindset" type="warn">
  Security gates should be noisy enough to catch risk, quiet enough that teams do not ignore them.
</Callout>
