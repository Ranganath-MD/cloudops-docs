## Flow

1. Source checkout
2. Dependency / SCA scan
3. SAST
4. Build & unit tests
5. DAST against staging
6. Gate on severity threshold

```yaml tab="CI sketch"
jobs:
  security:
    steps:
      - run: echo "SCA + SAST + policy gate"
```
