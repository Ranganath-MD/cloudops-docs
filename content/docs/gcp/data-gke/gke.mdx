GKE runs Kubernetes with Google managing the control plane.

## Autopilot vs Standard

| Mode | Best for |
| --- | --- |
| Autopilot | Less node ops, pay per pod |
| Standard | Custom node pools and daemons |

## Lab flow

1. Create a cluster
2. Get credentials
3. Deploy a sample app
4. Expose a Service
5. Inspect logs and metrics

```bash tab="Cluster"
gcloud container clusters create lab-gke \
  --zone us-central1-a \
  --num-nodes 2
gcloud container clusters get-credentials lab-gke --zone us-central1-a
```

```bash tab="Deploy"
kubectl create deployment web --image=nginx
kubectl expose deployment web --type=LoadBalancer --port=80
kubectl get svc web -w
```
