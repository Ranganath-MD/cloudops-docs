---
title: Amazon RDS
description: Managed relational databases with Multi-AZ and replicas
---

RDS runs managed MySQL, PostgreSQL, and other engines so you skip OS patching of the database host.

## Concepts

- **Primary instance** — read/write
- **Multi-AZ standby** — synchronous failover
- **Read replica** — scale reads asynchronously

## Lab

1. Create a MySQL RDS instance in private subnets
2. Allow the app security group on port 3306
3. Connect from an EC2 bastion/app host
4. Create a sample schema

```bash tab="Connect"
mysql -h mydb.xxxxx.us-east-1.rds.amazonaws.com -u admin -p
```

```sql tab="SQL"
CREATE DATABASE appdb;
USE appdb;
CREATE TABLE students (id INT PRIMARY KEY, name VARCHAR(100));
INSERT INTO students VALUES (1, 'Asha');
SELECT * FROM students;
```

<Callout title="Production tip" type="info">
  Keep RDS private. Use Multi-AZ for HA and automated backups with a tested restore drill.
</Callout>
