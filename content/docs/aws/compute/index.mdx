EC2 provides virtual servers inside your VPC.

## Launch checklist

- Choose AMI and instance type
- Place in the correct subnet
- Attach a security group (least privilege)
- Assign key pair / SSM role
- Tag `Name`, `Env`, `Owner`

```bash tab="Launch"
aws ec2 run-instances \
  --image-id ami-0abcdef1234567890 \
  --instance-type t3.micro \
  --subnet-id subnet-0123456789abcdef0 \
  --security-group-ids sg-0123456789abcdef0 \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=lab-web}]'
```

```bash tab="Connect"
# SSH
ssh -i lab.pem ec2-user@<public-ip>

# or Session Manager (no inbound SSH)
aws ssm start-session --target i-0123456789abcdef0
```

## AMIs and snapshots

Creating an AMI captures the root volume so you can launch identical instances later.

```bash tab="AMI"
aws ec2 create-image --instance-id i-0123 --name lab-web-v1 --no-reboot
```
