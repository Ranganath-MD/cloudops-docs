Load balancers distribute traffic and hide instance failures from users.

## ALB vs NLB

| Feature | ALB | NLB |
| --- | --- | --- |
| Layer | 7 (HTTP/HTTPS) | 4 (TCP/UDP) |
| Routing | Path / host rules | Port / IP |
| Typical use | Web apps, microservices | Ultra-low latency, static IP |

## Hands-on outline

1. Create two target groups
2. Register EC2 instances
3. Create an Application Load Balancer
4. Add listener rules
5. Attach the ALB to an Auto Scaling Group

```bash tab="Describe"
aws elbv2 describe-load-balancers \
  --query 'LoadBalancers[*].[LoadBalancerName,Type,State.Code]' \
  --output table
```

```bash tab="Health"
aws elbv2 describe-target-health --target-group-arn arn:aws:elasticloadbalancing:...
```

<Callout title="Tip" type="idea">
  Health checks should hit a cheap `/healthz` endpoint so unhealthy nodes leave rotation quickly.
</Callout>
