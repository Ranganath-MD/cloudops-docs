Amazon Bedrock provides managed foundation models through an API — no GPU servers to operate.

## Learning goals

- Know when to use managed AI APIs vs self-hosted models
- Call a foundation model from the console/CLI/SDK
- Keep prompts and outputs out of production logs when they contain sensitive data

```bash tab="List models"
aws bedrock list-foundation-models --region us-east-1 \
  --query 'modelSummaries[0:5].[modelId,providerName]' --output table
```

```bash tab="Invoke sketch"
aws bedrock-runtime invoke-model \
  --model-id amazon.titan-text-express-v1 \
  --body file://payload.json \
  --cli-binary-format raw-in-base64-out \
  outfile.json
```
