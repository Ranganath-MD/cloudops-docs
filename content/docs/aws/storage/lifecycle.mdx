---
title: Lifecycle
description: S3 lifecycle and retention policies
---

Lifecycle rules move or expire objects automatically to control cost and retention.

```json tab="Policy"
{
  "Rules": [
    {
      "ID": "archive-old-logs",
      "Status": "Enabled",
      "Filter": { "Prefix": "logs/" },
      "Transitions": [
        { "Days": 30, "StorageClass": "STANDARD_IA" },
        { "Days": 90, "StorageClass": "GLACIER" }
      ],
      "Expiration": { "Days": 365 }
    }
  ]
}
```

```bash tab="AWS CLI"
aws s3api put-bucket-lifecycle-configuration \
  --bucket my-app-assets \
  --lifecycle-configuration file://lifecycle.json
```

<Callout title="Compliance" type="warn">
  Confirm legal hold and retention requirements before enabling expiration.
</Callout>
