Combine DNS health checks with load balancers so clients always reach healthy endpoints.

## Patterns

| Pattern | Use when |
| --- | --- |
| ALB + target groups | HTTP/HTTPS microservices |
| NLB | TCP/UDP or static IP needs |
| Weighted DNS | Gradual cutovers and multi-region |

<Callout title="TTL tip" type="idea">
  Lower TTLs during migrations, then raise them once traffic is stable.
</Callout>

## Health checks

```yaml tab="ALB"
HealthCheckPath: /healthz
HealthCheckIntervalSeconds: 15
HealthyThresholdCount: 2
UnhealthyThresholdCount: 3
```

```yaml tab="Route 53"
Type: HTTPS
ResourcePath: /healthz
FailureThreshold: 3
RequestInterval: 30
```
