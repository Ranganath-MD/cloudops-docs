---
title: Routing
description: Route tables and traffic paths
---

Route tables decide where packets go next — internet gateways, NAT, peering, or transit.

<Tabs items={['Internet', 'Private outbound', 'Peering']}>
  <Tab value="Internet">
    Public subnet default route `0.0.0.0/0` → Internet Gateway.
  </Tab>
  <Tab value="Private outbound">
    Private subnet default route `0.0.0.0/0` → NAT Gateway.
  </Tab>
  <Tab value="Peering">
    Specific CIDR routes to peer VPC or Transit Gateway attachments.
  </Tab>
</Tabs>

<Callout title="Avoid asymmetric paths" type="warn">
  Return traffic must follow a compatible path, especially with firewalls and peering.
</Callout>
