Networking fundamentals underpin every VPC and cluster lab.

## Models

| OSI layer (examples) | TCP/IP view |
| --- | --- |
| 7 Application | HTTP, DNS, SSH |
| 4 Transport | TCP / UDP |
| 3 Network | IP routing |
| 2 Data link | Ethernet / MAC |
| 1 Physical | Cables / Wi-Fi |

## Addressing

- **MAC** — hardware address on a NIC
- **IPv4** — logical address; public vs private ranges
- **CIDR** — `10.0.0.0/16` style prefixes
- **Subnet mask** — splits network vs host bits

```bash tab="Inspect"
ip addr
ip route
cat /etc/resolv.conf
ping -c 3 8.8.8.8
```

## Services you must know

- **DNS** — name → IP
- **DHCP** — automatic addressing
- **Firewall / SG / NSG** — allow/deny traffic
- **NIC** — host network interface
