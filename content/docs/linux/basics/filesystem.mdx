Explore the Linux filesystem layout and everyday file/directory commands.

| Path | Purpose |
| --- | --- |
| `/etc` | Configuration |
| `/var` | Logs and variable data |
| `/home` | User homes |
| `/usr` | User programs |

```bash tab="Manage"
mkdir labs && cd labs
touch notes.txt
cp notes.txt notes.bak
find /etc -name "*.conf" | head
```
