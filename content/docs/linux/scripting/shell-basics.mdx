Shell scripting glues Linux admin tasks into repeatable automation.

## Essentials

- Positional parameters (`$1`, `$2`, `$@`)
- I/O redirection (`>`, `>>`, `2>`)
- Pipes (`|`)
- Variables and `export`
- Command substitution `$(...)`

```bash tab="Script"
#!/bin/bash
set -euo pipefail
NAME=${1:-world}
APP_ENV=${APP_ENV:-lab}
echo "Hello, $NAME (env=$APP_ENV)"
```

```bash tab="Pipes"
ps aux | grep java | awk '{print $2}'
journalctl -u nginx | tail -n 50 > nginx-tail.log
```
