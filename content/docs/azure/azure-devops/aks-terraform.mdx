## Capstone flow

Code commit → CI build → Docker image → push ACR → deploy AKS → monitoring

```bash tab="kubectl"
kubectl get nodes
kubectl apply -f k8s/
```

```terraform tab="Terraform"
resource "azurerm_kubernetes_cluster" "lab" {
  name                = "lab-aks"
  location            = azurerm_resource_group.lab.location
  resource_group_name = azurerm_resource_group.lab.name
  dns_prefix          = "labaks"
}
```
