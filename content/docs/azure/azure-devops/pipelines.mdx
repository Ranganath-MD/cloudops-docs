Azure Pipelines covers build (CI) and release (CD) with hosted or self-hosted agents.

## CI fundamentals

- Stages → Jobs → Steps/Tasks
- Triggers on branch commits
- Publish artifacts for release

```yaml tab="Build"
trigger:
  - main
pool:
  vmImage: ubuntu-latest
steps:
  - task: NodeTool@0
    inputs:
      versionSpec: '20.x'
  - script: |
      npm ci
      npm test
      npm run build
    displayName: Build and test
  - task: PublishBuildArtifacts@1
    inputs:
      pathToPublish: dist
      artifactName: drop
```

## CD strategies

| Strategy | Idea |
| --- | --- |
| Rolling | Replace instances gradually |
| Blue/Green | Switch traffic between two environments |
| Slots | App Service swap for near-zero downtime |

```yaml tab="Multi-stage"
stages:
  - stage: Build
    jobs:
      - job: build
        steps:
          - script: echo building
  - stage: Deploy
    dependsOn: Build
    jobs:
      - deployment: prod
        environment: production
        strategy:
          runOnce:
            deploy:
              steps:
                - script: echo deploying
```

<Callout title="Security" type="warn">
  Store secrets in Variable Groups / Key Vault — never hard-code tokens in YAML.
</Callout>
